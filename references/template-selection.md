# Template Selection

Choose the template style according to audience, occasion, and source content.

## Style Profiles

| Profile | Use for | Visual direction |
|---|---|---|
| `simple-blue` | academic reports, group meetings, course presentations | clean white/blue, readable, restrained |
| `sjtu-red` | official school events, anniversaries, institutional briefings | formal red, ceremonial, high authority |
| `deep-blue-gold` | thesis defense, research results, project review | dark blue, gold accent, formal and serious |
| `campus-poetic` | student activities, campus culture, admissions, club stories | campus imagery, warmer rhythm, more editorial |
| `minimal-white` | text-heavy drafts and dense research reviews | sparse, typographic, matrix-friendly |

## Decision Rules

- If the user says "学术汇报", "组会", "课程展示", choose `simple-blue` first.
- If the user says "答辩", "评审", "重大项目", choose `deep-blue-gold` or `minimal-white`.
- If the user says "校庆", "学院", "机关", "文明办", choose `sjtu-red`.
- If the user says "学生工作", "招生", "活动", choose `campus-poetic`.
- If the source is dense and the user gives no style preference, choose `simple-blue`.

## Template Audit

When a PPTX template is provided, inspect:

- slide size and aspect ratio
- cover/title/content/layout pages
- theme colors
- font style
- logo placement
- footer/page marker grammar
- typical chart/table style

Then reuse the template's grammar instead of inventing a new unrelated style.
