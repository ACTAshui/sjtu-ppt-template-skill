# Style System

This public skill describes a style direction and does not include official SJTU brand assets.

## Palette

Use these defaults when no template theme is provided:

- SJTU blue: `#004098`
- SJTU red: `#C8161E`
- Gold accent: `#BD9F68`
- Ink: `#172033`
- Body text: `#3A4658`
- Muted text: `#6B778A`
- Pale panel: `#F5F8FC`
- Rule line: `#D7E2F0`

## Typography

Use installed Chinese-friendly fonts:

- Microsoft YaHei
- DengXian
- HarmonyOS Sans SC
- Source Han Sans SC
- Noto Sans CJK SC
- Arial or Aptos for English fallback

## Layout Families

Use varied but coherent slide families:

- formal cover
- agenda or chapter divider
- literature/theme map
- metric or evidence page
- mechanism chain
- risk/comparison matrix
- timeline
- data chart or evidence page
- quote/case page
- closing synthesis

## Chart Style

For data-heavy or research decks, use [data-visualization.md](data-visualization.md).

- Keep chart backgrounds white or very pale.
- Use thin axes, light gridlines, and readable labels.
- Use SJTU red only for emphasis, not as the default color for every series.
- Pair SJTU blue with color-blind-safe teal, orange, purple, and muted gray when multiple groups are needed.
- Prefer direct labels and short annotations over crowded legends.
- Avoid 3D charts, heavy borders, chart shadows, glossy effects, and decorative gradients.

## Logo Policy

- Use exact user-provided logo files.
- Preserve aspect ratio.
- Do not redraw official marks.
- Do not place logos on noisy image backgrounds without adequate contrast.

## Text Rules

- Claim titles should be conclusions, not topic labels.
- Keep body copy short.
- Convert paragraphs into grouped arguments.
- Use source notes or appendix for citations when a slide would become crowded.
